# 3DR

> 3DR, Inc. designs and manufactures electronic systems for unmanned vehicles, drones and UAVs
> from Chula Vista, California — autopilots, GNSS receivers, telemetry radios, power modules,
> sensors, ESCs and a Remote ID module — built around open-source and open-hardware flight
> control (PX4, ArduPilot, DroneCAN, MAVLink). 3DR publishes **no public web API**: its machine
> interfaces are hardware buses and radio links, not HTTP endpoints.

Generated by API Evangelist on 2026-09-05 from this provider profile
(https://github.com/api-evangelist/3d-robotics). Not published by 3DR.

## Important entity note

Two distinct companies have traded as "3DR". 3DR, Inc. states on its own site: *"3DR Inc was a
distinct entity before the year 2023… our business is not providing any support for sold products
under the 3DR label prior to 2023."* The pre-2023 3D Robotics, Inc. built the Solo drone, the Site
Scan platform and the DroneKit developer program; its web API (api.3drobotics.com, DroneShare) is
decommissioned and its corporate domain 3drobotics.com now redirects to an unrelated company. Do
not attribute DroneKit or Site Scan to the company at 3dr.com today.

## What does not exist (probed 2026-09-05)

- No OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract on any 3DR host
- No /llms.txt, no /.well-known/security.txt, no /.well-known/api-catalog, no agent card
- No MCP server, no SDKs from the current entity, no status page, no changelog, no API pricing
- store.3dr.com/graphql answers HTTP 401 — that is BigCommerce's storefront API on a tenant
  domain, not a 3DR-designed or 3DR-documented interface
